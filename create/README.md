# create-futon

```sh
npm create futon@latest my-site
cd my-site
npm install
npm run dev
```

テーマを決めて敷くなら `npm create futon@latest my-site -- --theme heisei`(`plain` / `heisei` / `techou` / `kaomoji` / `vhs` / `keitai` / `mado` / `receipt`)。

futon 本体の説明は https://github.com/YasunaCoffee/futon

---

**English:** create-futon lays out a new site for [futon](https://github.com/YasunaCoffee/futon), an AI-friendly personal site engine.
Run the four lines above; add `-- --theme <name>` to start in a theme (`plain` / `heisei` / `techou` / `kaomoji` / `vhs` / `keitai` / `mado` / `receipt`).
The new folder includes `AGENTS.md`, so you can ask an AI agent things like "add an episode" right away.
