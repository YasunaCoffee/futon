# mado

futon についてくるテーマ。むかしのブラウザの窓(タイトルバー・ツールバー・アドレス・ステータスバー・タスクバー)に、左右フレームのピンクのホームページ。
404 は「ページを表示できません」。`site.json` に `"theme": "mado"` と書くと着られる。

書くと出る欄は techou と同じ(`hello`・`since`・`intro`・`characters`・棚の `cast`・`books`・`tech`)。
全部を使った例が futon の `samples/showcase/`(`node tools/try.mjs mado` で試着できる)。

文字は当時に寄せている:画面の文字は MS UI Gothic・MS Pゴシック 12px のビットマップに似たドットの PixelMplus(テーマに同梱、M+ FONT LICENSE)、タイトルは創英角ポップ体に似た Mochiy Pop P One(Google Fonts)。
