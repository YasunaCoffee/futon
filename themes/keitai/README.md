# keitai

futon についてくるテーマ。ピンクのガラケーの画面で読む。メニューは数字キー、新着はメール、キャラはアドレス帳
`site.json` に `"theme": "keitai"` と書くと着られる。

書くと出る欄は techou と同じ(`hello`・`since`・`intro`・`characters`・棚の `cast`・`books`・`tech`)。
全部を使った例が futon の `samples/showcase/`(`node tools/try.mjs keitai` で試着できる)。

文字は当時に寄せている:ガラケーの 12 ドットの文字に似た PixelMplus12(テーマに同梱、M+ FONT LICENSE)。大きさは 12・16・24px にしてある(3倍の画面でドットがきっちり並ぶ)。
