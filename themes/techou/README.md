# techou(てちょう)

futon についてくるテーマ。週間の手帳。`site.json` に `"theme": "techou"` と書くと着られる。

- ホームの最初は見開き:左はウィークリー(新着を1日1行、蛍光の黄緑の日付タブ、ピンクの罫線)、右は方眼(キャラの顔をピンクの枠のスタンプに、まんがをシールに)
- 蛍光ピンクのマーカー、赤いダブルクリップ、右の小口にインデックスのシール(メニュー)
- そのあとのページは、見出しと飾りの型を4つ順に回す(蛍光マーカー+しましまマステ / はんこ枠+付箋 / 手描きの丸+水玉マステ / テプラ風の黒いラベル+星シール)。絵の貼り方も型ごとに変わる
- 左のページの下の筆記体は `site.json` の `techou.word`(書かなければ happiness)

書くと出る欄:`intro`・`characters`(`face` があればスタンプに使う)・棚の `cast`・`books`・`tech`・`since`。
全部を使った例が futon の `samples/showcase/`(`node tools/try.mjs techou` で試着できる)。

文字は Google Fonts(Klee One・Zen Kaku Gothic New・Barlow Condensed・Yellowtail)から読む。
