# vhs

futon についてくるテーマ。電気みたいな青に黄色いマーカー、ビデオデッキのメニュー画面
`site.json` に `"theme": "vhs"` と書くと着られる。

書くと出る欄は techou と同じ(`hello`・`since`・`intro`・`characters`・棚の `cast`・`books`・`tech`)。
全部を使った例が futon の `samples/showcase/`(`node tools/try.mjs vhs` で試着できる)。

文字は当時に寄せている:ビデオの画面表示のドットの字(日本語は DotGothic16、数字と英字は VT323)。Google Fonts から読む。
